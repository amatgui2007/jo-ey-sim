Créditos
Jo-Ey-Sim no existiría sin el trabajo de las siguientes comunidades y proyectos. Todos los créditos van a sus autores originales.
Motor y cliente
* EDOPro — Project Ignis / Edoardo Lolletti. Cliente base del fork. AGPLv3+.
* ygopro-core — Fork de ocgcore usado por EDOPro. Motor de reglas y scripting.
* ocgcore original — Fluorohydride. Base histórica del motor.
Datos y scripts
* ProjectIgnis/CardScripts — Scripts Lua canónicos, pre-errata, anime, manga y videojuego.
* ProjectIgnis/BabelCDB — Bases de datos SQLite canónicas para EDOPro.
* ProjectIgnis/Distribution — Recursos de distribución, skins y configuración.
* DeltaPuppetOfStrings y DeltaHopeHarbinger — Repositorios delta de Project Ignis para actualizaciones incrementales.
Español
* ryoken08/CDBEsp — Base de datos de cartas en español para EDOPro.
API e imágenes
* YGOPRODeck — API v7 de datos de cartas e imágenes HD. Ver términos de uso.
* Konami / Yu-Gi-Oh! TCG — Fuente de reglas oficiales de Genesys y textos canónicos.
* Yugipedia y Yu-Gi-Oh! Fandom en Español — Fuentes alternativas de imágenes y textos, según configuración.
Inspiración de UI
* Master Duel (Konami) — Referencia de navegación por pestañas y fluidez.
* YGO Omega — Referencia de cliente moderno.
* Dueling Nexus — Referencia de usabilidad web.
* MDPro — Referencia de fork open source.
Desarrollo asistido por IA
* BetterDeepSeek — Asistencia de investigación, arquitectura y generación de código/documentación bajo dirección de Lyra.
Contribuir upstream
Si mejoras el motor, scripts o datos de forma genérica, considera enviar los cambios a los proyectos originales. Respeta sus guías (Project Ignis gestiona bugs por Discord, no por issues).
